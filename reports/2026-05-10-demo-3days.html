OpenAI 语音 Agent 2026-05-07

Realtime Voice 新模型：GPT-Realtime-2、Translate、Whisper

一句话：实时语音从“听懂并回答”往“边对话边推理、调用工具、执行任务”推进。

关键变化：OpenAI 发布 3 个 API 音频模型，覆盖实时语音推理、实时翻译、流式转写。GPT-Realtime-2 支持更长上下文、并行工具调用、更好的中断恢复和领域术语保持，面向客服、房产、旅行、医疗等生产语音 Agent 场景。

技术人为什么要关心：语音 Agent 的难点不只是延迟和音色，而是多轮状态、工具调用透明度、错误恢复和合规边界。这个方向会影响客服系统、移动端助手、车载交互和多语言会议产品。

信息边界：基于 OpenAI 官方发布页；性能数字来自官方描述，未独立复测。
