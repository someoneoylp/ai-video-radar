Agent 论文趋势：检索、技能增强和自进化能力库

页面结构

Hugging Face Daily Papers 页面通常按日期列出当天受到关注的论文。5 月 8 日的高信号内容集中在 Agent 系统：如何搜索、如何选择技能、如何积累技能，以及如何让 Agent 在长期任务中复用能力。

Agentic Search

相关论文标题指向一个核心问题：传统语义相似度检索并不总是适合 Agent。Agent 在执行任务时，可能需要直接与语料库交互、主动提出中间查询、逐步调整检索方向，而不是一次性拿 top-k 文档。

技术含义是，RAG 在 Agent 场景里会变得更像一个过程控制问题：什么时候检索、检索什么、如何验证资料是否足够，都会影响最终任务质量。

Skill-Augmented Agents

Skill-Augmented Agents 关注的是让 Agent 在强化学习或任务执行中拥有可复用技能。相比每次都让模型从零规划，技能库可以让系统把常见动作、工具调用模式和任务策略沉淀下来。

这和工程里的 workflow template、tool recipe、agent skill package 很接近。真正有价值的 Agent 平台，可能不是只提供一个强模型，而是提供一个能持续积累和选择技能的运行时。

SkillOS / Skill Curation

SkillOS 这一类标题强调技能整理和自进化。问题不只是“能不能学到技能”，还包括技能太多以后如何去重、分类、选择、更新，以及如何避免错误技能污染后续任务。

这对技术平台很重要：Agent 的长期记忆和技能库如果没有治理机制，会很快变成噪声仓库。未来 Agent infra 需要像管理代码库一样管理技能资产。

技术人该看什么

如果你在做 Agent/RAG 平台，建议把这类论文当成架构信号：检索模块、技能模块、记忆模块和执行模块会越来越分离。好的系统会减少一次性 prompt 的负担，把可复用能力沉淀为结构化资产。
